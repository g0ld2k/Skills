# Credits

This skill is a fork of the `pr` skill in [Matt Pocock](https://github.com/mattpocock)'s
[skills](https://github.com/mattpocock/skills) (version 1.3.1), used under the MIT
License below. The fork adds the opening sentences, the Conventional Commit title,
screenshot capture and `gh --attach` publishing, and the `needs-human-verification`
label for one-way doors.

The **Summary** section's menu of visuals (pseudocode, call trees, component trees,
file trees, Mermaid, diffs) and its placement guidance come from
[Dex Horthy](https://github.com/dexhorthy)'s
[`show-me`](https://github.com/humanlayer/humanlayer) skill, reproduced almost word
for word in the upstream `pr` skill and aimed at a diff instead of a live conversation.
